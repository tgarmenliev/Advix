# Advix — Документация по фази

Тази папка описва проекта **фаза по фаза**: какво прави всяка, кои решения са
взети и защо. Кодът е източникът на истината; тук е разказът зад него.

За кратко въведение и как да пуснеш проекта виж [главния README](../README.md).

## Фази

| # | Фаза | Съдържание |
|---|---|---|
| 1 | [Основа и автентикация](01-foundation-and-auth.md) | NestJS проект, конфигурация, JWT вход, роли, guards |
| 2 | [Multi-tenancy изолация](02-multi-tenancy.md) | Отделна база на организация, изолация при паралелни заявки |

| 4 | [Съдлъжници, имоти, финанси](04-family-property-financial.md) | Свързани лица, имоти за ипотека, финансови изчисления |
| 5 | [Кредитна заявка и workflow](05-loan-application-workflow.md) | Централният обект, state machine, права, flip на роли |

## Общ поглед

- **Стек:** NestJS + TypeScript (strict), PostgreSQL, Prisma 7, JWT, bcrypt.
- **Архитектура:** многотенантна (schema-per-tenant) с изолация през AsyncLocalStorage.
- **Пари:** всички суми са цели числа в стотинки (точна аритметика).
- **Тестове:** 142 автоматични теста, всички зелени.

## Как да четеш всяка фаза

Всеки файл следва един и същ шаблон:
**Цел → Какво включва → Ключови решения (и защо) → Правила и валидации →
Тестове → Как да се провери.**
